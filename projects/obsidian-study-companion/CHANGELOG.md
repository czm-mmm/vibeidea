# Changelog

## 0.1.3 — 2026-09-09

- 新增 `均衡` 模式，固定使用 GPT-5.6 Sol `medium`。
- 右栏模式按钮改为“快速 → 均衡 → 深入”循环切换，连接设置同步提供三档选择与可用性检查。

## 0.1.2 — 2026-09-09

- 将回答设置收敛为两个固定入口：`快速` 使用 GPT-5.6 Luna `max`，`深入` 使用 GPT-5.6 Sol `high`。
- 在右栏标题区显示当前回答模式，单击即可切换；连接设置同时检查两种模式是否可用。
- 后台预热在连接和模型列表之外提前创建当前笔记的 Codex 线程，减少第一次发送问题时的准备等待。
- 切换笔记、更新选区或切换回答模式后，自动为新上下文重新预热；并发预热只创建一次线程。

## 0.1.1 — 2026-09-06

- 启动 Obsidian 后在后台预热 Codex 连接，减少第一次提问的等待。
- 同一篇笔记或选区的连续追问复用 Codex 线程，不再每轮重新建立会话和重复发送历史。
- 自动按问题选择上下文：问候不附带笔记，优先使用选区，普通问题提取相关片段，明确总结全文时才发送整篇笔记。
- 发送过程中显示连接、建立或继续对话、思考和生成阶段；输入区同时显示本轮资料范围。
- 连接设置从本机 Codex 动态读取可用模型及对应推理强度，取消手工填写模型名称。

## 0.1.0 — 2026-09-03

- 明确标记为未经长期真实学习与公开用户测试的实验版，且尚未发布到 Obsidian Community Plugins。
- 从 `czm-mmm/vibeidea` 的 `projects/obsidian-study-companion` 目录迁移至独立仓库。迁移基于原仓库提交 `6ab4011279473933a839d8958b26a1d740793311`，原提交历史仍保留在原仓库。
- 提供笔记聊天、分步练习、学习事件保存与初版复习安排。
- 普通聊天布局：消息与回复分开排列，支持复制、停止、Enter 发送与 Shift+Enter 换行。
- 提供自拟示例、题目模板、安装脚本和独立自动测试。
- GitHub CI 加入 Chromium 布局与交互检查；发布 `v0.1.0` GitHub 预发布手动安装包。
- 当前为实验原型；长期学习画像、多笔记检索和图像录题等能力尚未实现。
