# SCOUT · 马戏团（H5 单机版）

桌游 **SCOUT**（Oink Games）的粉丝单机网页版：1 名玩家 + 2~4 个 AI，支持 3/4/5 人局，
纯前端离线运行（PWA）。规则逐条对照官方英文规则书 v3.0 实现，美术按 Oink 国际版
实物卡面还原。

## 快速开始

```bash
npm install
npm run dev      # http://localhost:5173
```

其他命令：`npm test`（Vitest 33 项）、`npm run build`（PWA 构建）、`npm run preview`。

## 玩法速记

- 每张牌上下各一个数字；手牌顺序锁定，只能整块打出：**同数 / 连续数字（升降皆可）/ 单张**。
- 压过当前牌型：张数多者强 → 等张数同数＞顺子 → 最低数字严格更大。
- 压不过就**侦察**：从牌型端点拿 1 张插入手牌（任意位置任意朝向），牌主 +1 金币。
- 每轮一次**双动**：侦察后立刻表演。
- 计分 = 收来的暗牌 + 金币 − 剩手牌；局数 = 人数，总分最高获胜。

详见 [docs/单机版设计.md](docs/单机版设计.md)（规则依据、架构、AI、美术、验证全记录）。

## 架构一句话

`src/core/` 是零依赖纯 TS 规则内核（引擎先校验后应用，非法动作抛 `RuleError`），
UI 通过 Pinia 只读镜像 + `dispatch` 交互——未来联机时把 `core/` 搬上服务器即成权威端。
